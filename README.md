# CLUTCH Co. website

A hand-coded rebuild of [clutchco.co.uk](https://www.clutchco.co.uk/) (currently a Squarespace site)
as a static site: plain HTML, one stylesheet, one small script, no build dependencies beyond Python 3.

Clutch Co. is a photography and videography studio based in the Lake District, working worldwide.

## Pages

| File | Live equivalent | What's on it |
| --- | --- | --- |
| `index.html` | `/` ("Motion") | Full-screen background video, then a scrolling reel of client logos |
| `coming-soon.html` | `/coming-soon` | Wordmark over a film-grain video, "WIP. Site coming soon.", enquiry form |
| `work-with-us.html` | `/work-with-us` | Freelancer network sign-up form |
| `contact.html` | `/contact` | Studio statement, email button, three-photo strip |

## Layout

```
src/pages/        page sources (edit these)
_partials/        shared <head> links, header/nav and footer
assets/css/       site.css — tokens, layout, components
assets/js/        site.js — mobile nav, background video, form handling
assets/img/       logo, hero poster frames, client logos, contact photos
assets/video/     the two background videos (muted, H.264)
design-system/    design system generated by the ui-ux-pro-max skill
docs/reference/   full-page screenshots of the live site (desktop + mobile)
scripts/build.py  stitches partials into the root-level *.html files
.claude/skills/   web design skills pulled from GitHub (see below)
```

## Editing and building

1. Edit `src/pages/*.html`, `_partials/*.html`, `assets/css/site.css` or `assets/js/site.js`.
   Never edit the root-level `*.html` files by hand; they are generated.
2. Rebuild:

   ```sh
   python3 scripts/build.py
   ```

3. Preview locally:

   ```sh
   python3 -m http.server 8765
   # open http://127.0.0.1:8765/
   ```

Deploy by uploading the repo root (minus `src/`, `_partials/`, `scripts/`, `docs/`) to any static
host: GitHub Pages, Netlify, Cloudflare Pages, Vercel.

## Connecting the forms

The enquiry form (`coming-soon.html`) and the freelancer form (`work-with-us.html`) post to the URL in
each `<form action="…">`. It is set to `REPLACE_WITH_FORM_ENDPOINT` until you pick a service, and the
page tells the visitor the form isn't connected yet.

- **Formspree**: create a form, copy its endpoint (`https://formspree.io/f/xxxxxxxx`) into `action`.
- **Netlify Forms**: add `data-netlify="true"` and `data-mode="native"` to the form and remove `action`.
- **Your own endpoint**: anything that accepts a multipart POST and returns 2xx.

Each form has a hidden `_gotcha` honeypot field and client-side validation that mirrors the required
fields on the live site.

## Design notes

- **Colour**: pure black background, white type, one red square (`#c83939`, sampled from the logo).
  Form fields are the mid-grey (`#5f5f5f`) used on the live site.
- **Type**: the live site uses Futura PT from Adobe Fonts, which can't be self-hosted. `Jost` from
  Google Fonts is the closest open geometric sans and is wired up in `_partials/head.html`. If you have
  an Adobe Fonts kit, swap the `<link>` and set `--font` in `site.css` to `"futura-pt"`.
- **Everything is uppercase** on the live site; that's set once on `body` and the form inputs opt out.
- **Motion**: the videos autoplay muted, pause when off-screen, and are replaced by their poster frame
  when the visitor has reduced motion enabled. The logo reel stops animating and wraps instead.
- **Known difference**: the live site's "Email" button on the contact page renders white-on-white.
  Here it is white with black text so it can be read.

## Assets pulled from the live site

All images and both videos were downloaded from the live site's Squarespace CDN on 22 Oct 2026 and
re-encoded for the web (photos resized to 2000px, videos to 720p/1080p H.264 without audio).
Instagram (`@clutchco.pro`) could not be pulled: Instagram now requires a logged-in session for every
profile and media endpoint, so no post images are included. Export them from the account (Settings →
Your activity → Download your information) and drop them in `assets/img/` when you have them.
